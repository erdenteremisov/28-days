# 28 дней — личный эксперимент

Mobile-first offline-first PWA. Наблюдение → гипотеза → эксперимент → измерение → вывод.

Никакой регистрации, никакого сервера, никакого AI API. Все данные пользователя
живут в IndexedDB в его браузере и никогда никуда не отправляются.

## Стек

TypeScript, компилируемый напрямую в нативные ES-модули, без React и без
сборщика. Ноль npm-зависимостей в рантайме, ноль шага сборки для деплоя.

```bash
npx tsc -p tsconfig.json   # компиляция src → app (после любой правки .ts)
python3 -m http.server 8080   # или npx serve .
```

Деплой — просто загрузить папку целиком на Cloudflare Pages / Vercel /
Netlify / GitHub Pages, build command пустой.

## Что изменено в этой версии

### 1. Онбординг — один экран вместо нескольких шагов

Три вопроса теперь на одном экране с тремя текстовыми полями и кнопкой
«Сохранить». Под ней — помощь для тех, кто не знает, что писать: кнопка
«Скопировать промт для интервью» копирует стартовый AI-промпт (дословно, без
изменений). Пользователь сам вставляет его во внешний AI, проходит интервью,
получает готовый блок с тремя ответами и вручную переносит его в поля выше —
никакого отдельного поля или режима для этого не добавлялось, как и просили.

### 2. Эксперименты — одно большое поле вместо структуры

`Experiment` упрощён до `{ number, hypothesis, startDayNumber, endDayNumber,
status }` — вся структура гипотезы (что менять, что наблюдать, критерии)
теперь живёт внутри текста, который формулирует AI, а приложение просто
хранит и показывает этот текст как есть. Старые поля (reason, change,
expectedResult, observations, result, conclusion) убраны из модели данных —
они физически перестали использоваться где-либо в интерфейсе.

Экспериментов теперь **три**: №1 (дни 8–14), №2 (дни 15–21), №3 (дни 22–28).
Раньше дни 22–28 были безымянной стадией «Закрепление» без своей сущности —
теперь это полноценный третий эксперимент, как и описано в новой логике
(необязательно новая гипотеза — может быть продолжением или проверкой
устойчивости прошлой).

### 3. Пять AI-промптов подключены дословно

`ai-prompt.ts` содержит все 5 промптов текстом как есть (стартовое интервью,
недели 1/2/3, финал), с точечной заменой `{{ONBOARDING_CONCERN}}` и подобных
токенов на реальные данные пользователя. Форматы `WEEK_N_DATA` — сырые данные
по дням без агрегатов (как и просили в этой версии промптов), количество
заполненных дней считается по факту наличия записи, ничего не додумывается за
пользователя.

Стартовый промпт интервью — статичный, без подстановок (используется до того,
как у пользователя вообще появляются данные).

### 4. Нижняя навигация — по-настоящему зафиксирована

Раньше нижняя навигация держалась на месте за счёт flex-раскладки — работало,
но не было "жёстким" фиксированием. Теперь `.bottom-nav` — `position: fixed`,
контент `.screen-container` — тоже `position: fixed` с собственным
`overflow-y: auto`, что гарантирует независимый скролл контента без переезда
навигации в любых условиях. Проверено на самом длинном экране (Сегодня) —
последняя кнопка «Сохранить день» видна полностью, навигация не перекрывает
ничего даже при полной прокрутке до конца.

### 5. Double-tap-zoom исправлен без потери доступности

Раньше в `viewport` meta стоял `maximum-scale=1` — это грубый глобальный
запрет любого масштабирования, включая pinch-zoom для людей с нарушениями
зрения. Убрал его. Вместо этого — `touch-action: manipulation` на `html` и на
интерактивных элементах: это убирает именно двойной тап-зум и фантомную
задержку/смещение при быстром двойном тапе, но оставляет pinch-zoom
доступным. Плюс `-webkit-tap-highlight-color: transparent` на кнопках, чтобы
убрать серую вспышку при тапе.

### 6. Тема — убрана «Системная»

Осталось два варианта: Светлая / Тёмная. Тип `ThemePreference` сужен до
`'light' | 'dark'`. Для тех, у кого в базе ещё остался старый выбор
"системная" (маловероятно на этом этапе, но на всякий случай) — `getMeta()`
автоматически переводит его в `'light'` при следующей загрузке.

### 7. Безопасность — устранены реальные XSS-места

Аудит показал: карточки экспериментов и их гипотеза, а также список
экспериментов на Итоге вставляли пользовательский текст прямо в `innerHTML`
шаблонных строк — если бы кто-то вставил гипотезу вида
`<img src=x onerror=...>`, она бы выполнилась как код. Исправлено: весь
пользовательский текст (гипотезы экспериментов, ответы онбординга) теперь
устанавливается через `textContent` или `.value`, а не через интерполяцию в
`innerHTML`. Проверено внедрением реальных `<img onerror>` и `<script>`
пейлоадов — теперь они отображаются как обычный текст, ничего не
выполняется. Экспорт/импорт JSON не менялся отдельно — этого не требуется,
поскольку опасность была именно в отображении данных, а не в их хранении, а
эти же экраны рендерят и импортированные данные тоже.

### 8. Мелкие проверки без изменений кода

- Данные корректно переживают reload/переустановку/переключение вкладок —
  архитектура IndexedDB не менялась.
- Пропущенные дни по-прежнему не ломают приложение — логика дат не менялась,
  только модель Experiment.

## Что НЕ добавлялось (по прямому указанию)

Никаких новых функций сверх списка: без соцфункций, рейтингов, достижений,
геймификации, аккаунтов, встроенного AI, сервера, push-уведомлений, новых
метрик или новых обязательных полей. В частности, ранее в разговоре
обсуждался экран-напоминание «Добавь на домашний экран» — сознательно НЕ
добавлял его в этой итерации, так как он не был частью текущего технического
задания. Скажите, если он всё же нужен.

## Проверено (Playwright, headless Chromium, эмуляция iPhone 13)

- Полный сценарий: онбординг → копирование промпта интервью → сохранение
  ответов → 28 дней данных → все 4 динамических промпта (недели 1/2/3 и
  финал) генерируются без незаполненных `{{TOKEN}}` и с данными всех трёх
  экспериментов.
- XSS-инъекция через ответы онбординга и гипотезу эксперимента — payload
  отображается как текст, alert не срабатывает.
- Нижняя навигация остаётся на месте и не перекрывает контент при полной
  прокрутке экрана «Сегодня» (самого длинного).
- `touch-action: manipulation` применяется на `<html>`.
- Тема: ровно 2 варианта (Светлая/Тёмная), переключение мгновенное, значение
  сохраняется и переживает reload.
- Экран «Эксперимент» показывает ровно 3 карточки, каждая с одним полем.
- Сценарий с пропущенным днём — на Главной по-прежнему появляется подсказка
  «День N ещё не заполнен», переход в Сегодня открывает нужный день.
- Полная навигация по всем 5 вкладкам без ошибок в консоли.

## Известные ограничения (не менялись в этой итерации)

- Настоящие iOS/Android устройства и нативный диалог установки PWA — всё ещё
  не проверялись физически, только эмуляция.
- Иконка приложения — geometric placeholder.
- Формат «Первичных аналитических наблюдений» в финальном промпте предыдущей
  версии убран вместе со старыми промптами — новые 5 промптов его не требуют.
